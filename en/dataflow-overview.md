## Data & Analytics > DataFlow > Overview

* This is a service that allows you to easily create desired ETL (extract-transform-load) flows with Drag & Drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation operations on input messages.
* Provides features to run flows periodically at desired times.

## Special Features

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platform and AI Services to be added in the future.
    * Will be available for various uses including business analysis and AI service development.

## Key Features

* You can create flows that transform data from original data sources through filters and deliver it to desired data sources.
* You can easily configure flow logic through Drag & Drop and simple settings.
* Supports easy integration with other products in NHN Cloud.
* You can execute flows at desired times through scheduling features.
