## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the desired ETL (extract-transform-load) flow through drag & drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation operations on input messages.
* Provides the ability to periodically run flows at desired times.

## Key Features

* Supports seamless integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Expected to be applicable in various ways, including business analysis and AI service development.

## Main Features

* You can create a flow that transforms data received from the original data source through filters and delivers it to the desired data source.
* Flow logic can be easily configured through drag & drop and simple settings.
* Supports seamless integration with other products within NHN Cloud.
* Through scheduling functionality, you can run flows at desired times.
