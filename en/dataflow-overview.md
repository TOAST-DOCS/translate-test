## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the desired ETL (extract-transform-load) flow through drag & drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation tasks on input messages.
* Provides the ability to periodically run flows at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables secure and simple infrastructure resource management that reduces user burden.
* Planning to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Will be available for use in various areas such as business analysis and AI service development.

## Main Features

* You can create a flow that transforms data ingested from a source data source through filters and delivers it to the desired data source.
* Flow logic can be easily configured through drag & drop and simple settings.
* Supports easy integration with other services within NHN Cloud.
* Scheduling functionality allows you to run flows at desired times.
