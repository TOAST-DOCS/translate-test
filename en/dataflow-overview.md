## Data & Analytics > DataFlow > Overview

* Enables you to easily create the ETL (extract-transform-load) flow you want with drag-and-drop and simple configuration.
* Provides encryption filters, parsing filters, and more for performing simple transformation operations on input messages.
* Provides the feature to run flows periodically at the time you want.

## Benefits

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management, reducing the burden on users.
* Plans to strengthen integration with various Data Platform and AI Service offerings to be added in the future.
    * Will be available for various use cases, including business analytics and AI service development.

## Main features

* Allows you to create a flow that transforms data ingested from a source data source through filters and delivers it to the desired destination data source.
* Allows you to easily configure flow logic with drag-and-drop and simple settings.
* Supports easy integration with other NHN Cloud products.
* Scheduling feature allows you to run flows at the time you want.
