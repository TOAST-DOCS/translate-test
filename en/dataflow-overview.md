## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create ETL (extract-transform-load) flows with drag & drop and simple configuration.
* Provides encryption filters and parsing filters that perform simple transformation operations on input messages.
* Provides functionality to periodically execute flows at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables safe and simple infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Will be usable in various ways such as business analysis and AI service development.

## Main Features

* You can create flows that transform data received from original data sources through filters and deliver it to desired data sources.
* You can easily set flow logic through drag & drop and simple configuration.
* Supports easy integration with other products within NHN Cloud.
* With the scheduling feature, you can execute flows at desired times.
