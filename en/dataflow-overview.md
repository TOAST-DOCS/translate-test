## Data & Analytics > DataFlow > Overview

* Enables you to create desired ETL (extract-transform-load) flows with drag and drop and simple settings.
* Provides encryption filters, parsing filters, and other filters to perform simple transformation tasks on input messages.
* Provides a feature to run flows periodically at your desired time.

## Benefits

* Supports integration with NHN Cloud services.
* Enables you to safely manage infrastructure resources with reduced user burden.
* Plans to strengthen integration with various Data Platform and AI Service products to be added in the future.
    * Can be utilized in various ways, such as business analysis and AI service development.

## Main Features

* You can create flows that receive data from the original data source, transform it through filters, and deliver it to the desired data source.
* You can set up flow logic with drag and drop and simple settings.
* Supports integration with other NHN Cloud products.
* You can run flows at your desired time using the scheduling feature.
