## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the desired ETL (extract-transform-load) flows with Drag & Drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation tasks on input messages.
* Provides the ability to run flows periodically at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management to reduce user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * It will be possible to utilize the service in various ways such as business analysis and AI service development.

## Main Functions

* You can create flows that transform data ingested from the original data source through filters and deliver it to the desired data source.
* You can easily set up flow logic through Drag & Drop and simple configuration.
* Supports easy integration with other products within NHN Cloud.
* Through the scheduling function, you can run flows at desired times.
