## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the desired ETL (extract-transform-load) flows through Drag & Drop and simple configuration.
* Provides encryption filters, parsing filters, and other features that allow you to perform simple transformation operations on input messages.
* Provides functionality to run flows periodically at desired times.

## Key Strengths

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to enhance integration with various Data Platforms and AI Services in the future.
    * Will enable utilization in multiple areas such as business analysis and AI service development.

## Key Features

* You can create flows that transform data ingested from original data sources through filters and deliver them to desired data sources.
* Flow logic can be easily configured through Drag & Drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* Scheduling functionality allows you to run flows at desired times.
