## Data & Analytics > DataFlow > Overview

* This service allows you to easily create the ETL (extract-transform-load) flows you want through drag & drop and simple configuration.
* It provides encryption filters and parsing filters that can perform simple transformation operations on input messages.
* It provides the ability to run flows periodically at desired times.

## Key Features

* It supports easy integration with NHN Cloud services.
* It enables safe and easy infrastructure resource management that reduces the burden on users.
* We plan to strengthen integration with various Data Platforms and AI Services that will be added in the future.
    * It will be available for use in various fields such as business analysis and AI service development.

## Main Functions

* You can create flows that transform data ingested from original data sources through filters and deliver it to desired data sources.
* You can easily configure flow logic through drag & drop and simple settings.
* It supports easy integration with other products in NHN Cloud.
* You can run flows at desired times through the scheduling function.
