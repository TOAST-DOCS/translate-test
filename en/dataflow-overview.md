## Data & Analytics > DataFlow > Overview

* A service that allows you to create desired ETL (extract-transform-load) flows with Drag & Drop and simple settings.
* Provides encryption filters and parsing filters that perform simple transformation tasks on input messages.
* Provides the functionality to periodically run flows at desired times.

## Benefits

* Supports easy integration with NHN Cloud services.
* Enables secure and simple infrastructure resource management to reduce user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Can be used in various areas such as business analysis and AI service development.

## Main features

* You can create flows that transform data from source systems through filters and deliver it to target systems.
* You can set up flow logic with Drag & Drop and simple settings.
* Supports easy integration with other NHN Cloud services.
* You can run flows at desired times through the scheduling functionality.
