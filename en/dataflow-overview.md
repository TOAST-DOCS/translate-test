## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create desired ETL (extract-transform-load) flows through drag & drop and simple configuration.
* Provides encryption filters, parsing filters, and other tools to perform simple transformation operations on input messages.
* Provides the ability to run flows periodically at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Provides safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Will be able to be utilized in various ways such as business analysis and AI service development.

## Main Features

* You can create a flow that transforms data received from the original data source through filters and delivers it to the desired data source.
* Flow logic can be easily configured through drag & drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* Through the scheduling feature, you can run flows at desired times.
