## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create desired ETL (extract-transform-load) flows through drag & drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation operations on input messages.
* Provides the ability to run flows periodically at desired times.

## Key Features

* Easy integration with NHN Cloud services is supported.
* Safe and easy infrastructure resource management that reduces user burden is possible.
* We plan to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * It will be possible to utilize for various purposes such as business analysis and AI service development.

## Main Functions

* You can create flows that transform data received from original data sources through filters and deliver them to desired data sources.
* Flow logic can be easily configured through drag & drop and simple settings.
* Easy integration with other products within NHN Cloud is supported.
* Through scheduling functionality, you can run flows at desired times.
