## Data & Analytics > DataFlow > Overview

* A service that makes it easy to create the desired ETL (extract-transform-load) flows through Drag & Drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation tasks on input messages.
* Provides the ability to periodically run flows at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables secure and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Will be usable in various ways such as business analysis and AI service development.

## Main Functions

* You can create a flow that transforms data from an original data source through filters and delivers it to a desired data source.
* You can easily set up flow logic through Drag & Drop and simple configuration.
* Supports easy integration with other products within NHN Cloud.
* Through the scheduling function, you can run flows at desired times.
