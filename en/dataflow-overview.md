## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the ETL (extract-transform-load) flows you want with drag & drop and simple configuration.
* Provides encryption filters, parsing filters, and other features that can perform simple transformation tasks on input messages.
* Provides the ability to periodically run flows at desired times.

## Key Benefits

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platform and AI Services that will be added in the future.
    * It will be available for various uses such as business analysis and AI service development.

## Key Features

* You can create flows that transform data received from original data sources through filters and deliver it to desired data sources.
* You can easily configure flow logic through drag & drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* You can run flows at desired times through scheduling functionality.
