## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create ETL (extract-transform-load) flows with drag and drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformations on input messages.
* Provides functionality to periodically execute flows at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Will be available for use in various ways, such as business analysis and AI service development.

## Main Features

* You can create flows that transform data received from source data sources through filters and deliver it to desired data sources.
* Flow logic can be easily configured through drag and drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* Through scheduling functionality, you can execute flows at desired times.
