## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create desired ETL (extract-transform-load) flows through drag & drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation tasks on input messages.
* Provides the ability to execute flows periodically at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * Can be utilized in various ways such as business analysis and AI service development.

## Main Functions

* You can create flows that transform data received from a source data source through filters and deliver it to the desired data source.
* You can easily set flow logic through drag & drop and simple configuration.
* Supports easy integration with other NHN Cloud products.
* Through scheduling functionality, you can execute flows at desired times.
