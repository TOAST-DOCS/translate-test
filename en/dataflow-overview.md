## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create the ETL (extract-transform-load) flows you want through Drag & Drop and simple configuration.
* Provides encryption filters and parsing filters that can perform simple transformation tasks on input messages.
* Provides functionality to run flows periodically at desired times.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management that reduces user burden.
* We plan to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * It will be available for various purposes such as business analytics and AI service development.

## Main Capabilities

* You can create flows that transform data received from original data sources through filters and deliver it to desired data sources.
* You can easily configure flow logic through Drag & Drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* Through scheduling functionality, you can run flows at desired times.
