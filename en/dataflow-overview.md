## Data & Analytics > DataFlow > Overview

* This is a service that allows you to easily create desired ETL (extract-transform-load) flows through drag & drop and simple configuration.
* It provides encryption filters and parsing filters that can perform simple transformation operations on input messages.
* It provides the ability to periodically execute flows at desired times.

## Benefits

* Supports easy integration with NHN Cloud services.
* Enables safe and easy infrastructure resource management, reducing the burden on users.
* Plans to strengthen integration with various Data Platforms and AI Services to be added in the future.
    * It will be possible to use it in various ways, such as business analysis and AI service development.

## Key Features

* You can create flows that take data from the original data source, transform it using filters, and deliver it to the desired data source.
* You can easily set up flow logic through drag & drop and simple configuration.
* Supports easy integration with other products within NHN Cloud.
* You can execute flows at desired times through the scheduling feature.
