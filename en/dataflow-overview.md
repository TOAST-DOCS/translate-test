## Data & Analytics > DataFlow > Overview

* A service that allows you to easily create ETL (extract-transform-load) flows through drag & drop and simple configuration.
* Provides encryption filters and parsing filters that enable simple transformations on input messages.
* Provides functionality to run flows periodically at your desired time.

## Key Features

* Supports easy integration with NHN Cloud services.
* Enables secure and simple infrastructure resource management that reduces user burden.
* Plans to strengthen integration with various Data Platform and AI Services to be added in the future.
    * Will be available for various use cases such as business analysis and AI service development.

## Main Features

* You can create flows that transform data ingested from original data sources through filters and deliver it to desired data sources.
* Flow logic can be easily configured through drag & drop and simple settings.
* Supports easy integration with other products within NHN Cloud.
* Through the scheduling function, you can run flows at your desired time.
