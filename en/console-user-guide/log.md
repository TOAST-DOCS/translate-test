# Log

**Security > Cloud Access > Console User Guide > Log**

In the **Log** tab, you can search various logs generated during the operation of the Cloud Access service in real-time.

<br>

<a id="traffic"></a>
## Traffic { #traffic }

![traffic_log.PNG](../../static/images/2025.06.24/traffic_log.png)

You can view communication traffic logs that are generated when users connect to instances using the Cloud Access service agent.
* Logs can be searched for up to three months in the past, with each search covering a one-month period.

<br>

<a id="audit"></a>
## Audit { #audit }

![audit_log.PNG](../../static/images/2025.06.24/audit_log.png)

You can search logs related to changes in the Cloud Access service, such as creating or deleting user policies.
* Logs can be searched for up to one month at a time and are also available in the organizational service CloudTrail.

<br>

<a id="user"></a>
## User { #user }

![audit_log.PNG](../../static/images/2025.06.24/user_log.png)

You can search all logs generated by the agent while a user is logged in and using Cloud Access.

<br>

<a id="download-as-excel"></a>
## Download as Excel { #download-as-excel }

You can download the log search results to an excel file.

<br>

!!! tip "Note"
    * Traffic logs are retained for a maximum of 7 days or 50,000 entries. If either condition is exceeded, the oldest logs are deleted in order (overwritten).
        * If long-term storage is required, it is recommended to use **Remote Log Transfer Settings** in the **Settings** tab.
