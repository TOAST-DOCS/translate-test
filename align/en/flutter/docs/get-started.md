## Get Started { #get-started }

<a id="supported-environment"></a>
### Supported Environment { #supported-environment }

- Android 4.4 or later
- iOS 13.0 or later
- React Native 0.69.12 or later

<a id="download-nhn-appguard-sdk"></a>
### Download NHN AppGuard SDK { #download-nhn-appguard-sdk }

You can download the NHN AppGuard SDK from the NHN Cloud console.

1. Access the NHN Cloud console and go to **Security > NHN AppGuard**.
2. Select the **App Protection** tab.
3. Click **Download SDK** at the top.
4. Click **React Native SDK** to download the **AppGuard-ReactNative.zip** file.
