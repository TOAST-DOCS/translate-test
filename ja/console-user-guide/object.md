<a id="object"></a>
## オブジェクト { #object }

**Security > Network Firewall > コンソール使用ガイド > オブジェクト**

**オブジェクト**タブでは、ポリシーを作成する際に使用するIP、ポートを作成及び管理します。

<br>

<a id="configure-objects"></a>
## オブジェクトの設定 { #configure-objects }

<a id="add"></a>
### 追加 { #add }

* 必須項目を入力してオブジェクトを作成します。
    * オブジェクトは、IPとポートの2つの形式で追加できます。
    ![(object2)](https://static.toastoven.net/prod_nfw/26.07.28/2.console-user-guide/4.object/object2.png)

<a id="modify"></a>
### 修正 { #modify }

* **修正**をクリックしてオブジェクトを修正できます。
    * タイプは修正できません。

<a id="delete"></a>
### 削除 { #delete }

* **削除**をクリックしてオブジェクトを削除できます。
    * Network Firewallで自動作成されたオブジェクトは、修正や削除ができません。

<a id="additional-features"></a>
### 追加機能 { #additional-features }

* インスタンスオブジェクトの追加: Network Firewallが作成されたプロジェクト内にあるインスタンスを活用してオブジェクトを追加できます。
* テンプレートのダウンロード: 一括登録に必要なテンプレートファイルをダウンロードします。
* オブジェクトの一括登録: ダウンロードしたテンプレートを使用して一括でオブジェクトを登録できます。
* オブジェクトの一括ダウンロード: **[オブジェクト]** タブに作成されているIPまたはポートオブジェクト全体をそれぞれ一度にダウンロードできます。

!!! tip "ポイント"
    * グループオブジェクト作成時、グループオブジェクトは追加できません（単一または範囲オブジェクトのみ選択して追加可能）。
    * オブジェクト修正時、タイプは修正できません。
    * インスタンスオブジェクトの追加機能は、インスタンスとは関係なく、単純にインスタンスの名前とプライベートIPアドレスのみを参照してオブジェクトを作成します。作成したオブジェクトは **[オブジェクト]** タブで管理します。

!!! danger "注意"
    ポリシーで使用中のオブジェクトを削除した場合、削除後にALLオブジェクトに変更されます。削除する際はご注意ください。
