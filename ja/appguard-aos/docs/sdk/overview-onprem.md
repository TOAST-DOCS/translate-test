# SDK連携ガイド

<a id="sdk-integration"></a>
## SDK連携 { #sdk-integration }

NHN AppGuardの保護作業を行う場合、SDKの連携は必須ではないため、保護作業のみでNHN AppGuardを利用できます。

ただし、SDKを連携すると、コールバック登録、User ID連携、アプリ証明など、より高度なNHN AppGuardの機能を利用できます。

保護作業については、[2. 保護作業](../protection/cli-onprem.md)の章をご参照ください。
アプリ証明SDKについては、[6.3 アプリ証明 SDKの連携](../app-attestation/sdk.md)の章を参照してください。
