## Machine Learning > NHN Cloud Foundry > 概要 { #foundry.overview }

NHN Cloud Foundry は、データ収集から加工、分析、AI モデルサービングまで一か所で実行できる AI データプラットフォームサービスです。
データを積載してビジュアルワークフローで加工した後、クエリ・チャート・ダッシュボードで分析したり、AI モデルを接続したアプリを作成して推論結果をサービスに活用できます。

<a id="main.feature"></a>

## 主な機能 { #main.feature }

| 機能 | 説明 |
| --- | --- |
| **データソース** | 分析するデータを保存する単位です。スキーマを定義してデータソースを作成しデータを積載します。作成済みのデータソースには Ingest API でデータを追加または更新できます。 |
| **パイプライン** | データソースのデータをノードを接続したワークフローで加工し、分析可能なデータセットに変換します。バッチスケジュールに基づく自動実行をサポートします。 |
| **分析** | データを SQL **クエリ**で照会し、**チャート**で可視化し、**ダッシュボード**で統合モニタリングできます。 |
| **アプリ** | AI モデルをデータに接続してアプリを作成・管理します。推論結果はコンソールと API で確認できます。 |

<a id="datasource"></a>

## データソース { #datasource }

データソースは、NHN Cloud Foundry で分析するデータを保存する単位です。
スキーマを定義してデータソースを作成すると、データがテーブルとして積載され、以降はパイプライン・分析・アプリでこのデータを使用します。

データソースはコンソールで作成し、作成時にデータを一緒にアップロードできます。
作成済みのデータソースにデータを追加または更新する場合は、Ingest API を使用します。

<a id="pipeline"></a>

## パイプライン { #pipeline }

データソースのデータをノードを接続したビジュアルワークフローで加工し、分析可能なデータセットに変換する機能です。

- ソースデータの接続およびスキーマの自動検出
- 行フィルタリング、カラム加工、集計、ジョイン、ユニオンなどの変換処理
- バッチスケジュール設定に基づく自動実行
- コンピューティングリソースの設定および実行履歴管理

<a id="analysis"></a>

## 分析 { #analysis }

データソースに保存されたデータを照会・可視化・モニタリングします。
クエリでデータを確認し、チャートを作成してダッシュボードに配置する順序で使用します。

| 機能 | 説明 |
| --- | --- |
| クエリ | SQL を使用してデータソースのデータを照会し、実行履歴を管理します。 |
| チャート | 照会したデータを可視化します。 |
| ダッシュボード | 複数のチャートを 1 つの画面に配置して統合モニタリングします。 |

<a id="app"></a>

## アプリ { #app }

AI モデルをデータに接続して推論サービスを提供するアプリを作成・管理する機能です。
使用するモデルを選択してデータソースを接続すると、学習とデプロイが自動的に進み、アプリがアクティブ状態になると推論結果を活用できます。

推論結果はコンソールから直接呼び出して確認するか、API でリクエストできます。

<a id="public.api"></a>

## API { #public.api }

NHN Cloud Foundry は、コンソール以外にも API を提供します。
作成済みのデータソースにデータを追加・更新する Ingest API と、作成したアプリの推論結果をリクエストしてユーザー反応イベントを送信する API を使用できます。

詳細については、[APIガイド](./api-guide/)を参照してください。

<a id="target"></a>

## サービス対象 { #target }

- データインフラを自前で構築せずに、データ積載・加工・分析環境が必要なチーム
- 分散したデータを一か所に集めて定期的に加工し、メトリクスで確認したいサービス
- 独自のモデル学習・サービング環境なしに AI 推論結果をサービスに適用したいチーム
