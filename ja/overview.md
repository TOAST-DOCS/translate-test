## Network > Service Gateway > 概要

**Service Gateway** サービスを使用すると、**フローティング IP** を使わずにトラフィックがインターネットを経由せず、**VPC** 外部の NHN Cloud の**サービス**や、他のユーザーが公開した**ユーザー定義エンドポイント**を利用できます。**サービスゲートウェイの作成**時に選択された接続先と自動的に割り当てられた IP は 1:1接続関係を維持し、**VPC** では**サービスゲートウェイ**の IP を使用して NHN Cloud の内部ネットワークを経由し、対象のサービスを安全に利用できます。

### 主な機能

* VPC からインターネットを経由せず、サービスゲートウェイが提供する NHN Cloud のサービスに接続できます。
* サービスゲートウェイの作成時に、接続タイプとして**サービスエンドポイント**(NHN Cloud が提供するサービス)または**ユーザー定義エンドポイント**(他のユーザーが公開したリソース)を選択できます。
* 自身のロードバランサーを**ユーザー定義エンドポイント**として公開し、接続を許可するプロジェクトを指定して、他のプロジェクトがサービスゲートウェイ経由で接続できるように共有できます。
* サービスゲートウェイの作成時は、サービスリストに表示されているサービスのみ利用できます。
* サービスゲートウェイの IP アドレスは、サービスゲートウェイの作成時に選択された接続先と 1:1 で対応します。
* VPC の VM Instance からサービスゲートウェイの IP アドレスに通信すると、サービスゲートウェイに接続された対象と通信されます。
* サービスゲートウェイは現在、韓国(パンギョ)、韓国(ピョンチョン)、韓国(クァンジュ)リージョンで提供されています。今後、他のリージョンもサポートする予定です。
* ただし、ユーザー定義エンドポイントは韓国(パンギョ)、韓国(ピョンチョン)リージョンのみでサポートしています。

### 提供サービス

VPC の VM Instance からインターネットを経由せず NHN Cloud のサービスへのアクセスが必要な場合は、サービスゲートウェイで提供されるサービスを選択してサービスゲートウェイを作成します。
詳細な使用方法については、[Service Gateway > コンソール使用ガイド](/Network/Service%20Gateway/ja/console-guide/)を参照してください。

提供サービスについては、[**サービスエンドポイント**](/Network/Service%20Gateway/ja/service-endpoint/)を参照してください。提供されるサービスは徐々に拡大していく予定です。

### ユーザー定義エンドポイント

NHN Cloud が提供するサービス以外に、他のユーザーが公開したリソースにもサービスゲートウェイで接続できます。リソース所有者は自身のロードバランサーをユーザー定義エンドポイントとして公開し、共有用のサービス名を発行して接続を許可する相手に伝えます。利用者は受け取ったサービス名でサービスゲートウェイを作成して接続します。
詳細な使用方法については、[Service Gateway > コンソール使用ガイド](/Network/Service%20Gateway/ja/console-guide/)を参照してください。
