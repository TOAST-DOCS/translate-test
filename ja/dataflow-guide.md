## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは次のような順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 希望するプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかを確認します。

## 管理

フローメタデータ情報を照会し、管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定された基準でフローを検索します。

* フロー名を基準に検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

指定された条件でフローを検索します。

* フロー状態値に基づくフィルタリングオプションを提供します。

### フロー一覧

照会結果をテーブル形式でフローを表示します。

* 簡単なフロームメタデータと現在のフロー実行状態を表示します。
* 最終更新日を基準に並べ替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定の状態のフローのみ照会できます。
* 一度照会されたフローは**更新**を押して照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会でき、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態                                         | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などにより、エラーが発生しました。継続して<b>ERROR</b>が発生する場合は、**カスタマーサポート > お問い合わせ**でお問い合わせください。 |
| STOP\_FAILED   | フロー停止要求に失敗しました。 |
| STOPPED        | フローが停止されました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行過程で原因不明のエラーが発生しました。継続して<b>UNKNOWN</b>が発生する場合は、**カスタマーサポート > お問い合わせ**でお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更されたときに通知メールを受け取ることができます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフロームメタデータを作成します。
* フロー名は他のフローと重複が可能です。
* フロー目的に応じた実行モードを選択します。
* フロームテンプレートを指定して、ユーザーが希望する機能のフローを簡単に読み込むことができます。
* フローを実行するためのインスタンスタイプを設定できます。 

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフロームメタデータに反映させます。
* フロームテンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フローを実行するためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複写

既存のフロー定義を使用して新しいメタデータを作成します。

* 既存フローの名前に`_copy`文言が追加された新しいメタデータを作成します。
* 既存フローが持つフロームロジックをそのまま複写します。
* 実行中のフローも複写が可能です。
* 実行中のフローは停止状態で複写します。
* フローの現在の保存状態が一時保存の場合、既存フローの最後の保存バージョンは複写しません。
* スケジューラが登録されたフローを複写しても、複写したフローにはスケジューラが登録されません。
* 複写したフローは既存フローと完全に独立したフローです。

### フロー削除

フロームメタデータを削除します。

* フロームメタデータを完全に削除します。
* 削除されたフローは復旧できません。
* 実行中のフローは削除できません。

### さらに表示 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つだけ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始します。
* 1度も保存せず一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラで実行中でも、ユーザーが開始したフローと同じように、フローを開始できません。

### さらに表示 - フロー停止
* 実行準備中または実行中、ドレイニング中のフローを停止できます。
* 残りイベントは処理せず停止します。

### さらに表示 - フロードレイニング後に停止
* 実行中のフローをドレイニング後に停止できます。
* ドレイニングはフローの残りイベントを処理することを意味します。
* タイムアウト時間を超過する場合、ドレイニングが終了していなくても停止します。
* タイムアウト時間が残っている状態でドレイニングが終了する場合、すぐに停止します。
* ドレイニング中のフローはフロー停止を通じてすぐに停止できます。
