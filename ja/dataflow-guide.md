## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは次の順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 希望するプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定し、フローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認し、フローが正常に実行されたかを確認します。

## 管理

フローメタデータ情報を照会し、管理するページです。
**Data & Analytics > DataFlow > 管理** をクリックします。

### 検索

与えられた基準でフローを検索します。

* フロー名を基準として検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

与えられた条件でフローを検索します。

* フロー状態値によるフィルタリングオプションを提供します。

### フロー一覧

照会結果のフローをテーブル形式で表示します。

* 簡単なフローメタデータと現在のフロー実行状態を表示します。
* 最近の修正日を基準として並べ替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定の状態のフローのみを照会できます。
* 一度照会されたフローは **更新** をクリックして照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会し、**前へ** および **次へ** をクリックしてページを移動できます。

#### フロー状態情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行リクエストに失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足し、実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などにより、エラーが発生しました。継続的に <b>ERROR</b> が発生する場合は **カスタマーサポート > お問い合わせ** までお問い合わせください。 |
| STOP\_FAILED   | フロー終了リクエストに失敗しました。 |
| STOPPED        | フローが終了されました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行過程で不明な原因によりエラーが発生しました。継続的に <b>UNKNOWN</b> が発生する場合は **カスタマーサポート > お問い合わせ** までお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更された際に通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* 基本受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの **DataFlow ADMIN** 役割を持つメンバー


### フロー作成

フローを定義するためのメタデータを作成します。

* フロー識別のため、名前と説明を追加してフローメタデータを作成します。
* フロー名は他のフローと重複することができます。
* フローの目的による実行モードを選択します。
* フローテンプレートを指定し、ユーザーが希望する機能のフローを簡単に読み込むことができます。
* フローを実行するためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正し、フローメタデータに反映します。
* フローテンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フローを実行するためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次回フロー実行から適用されます。

### フロー複製

既存のフロー定義を使用して新しいメタデータを作成します。

* 既存フローの名前に `_copy` 文句が追加された新しいメタデータを作成します。
* 既存フローが持つフローロジックをそのまま複製します。
* 実行中のフローも複製が可能です。
* 実行中のフローは停止状態で複製されます。
* フローの現在保存状態が一時保存の場合、既存フローの最終保存バージョンは複製されません。
* スケジューラーが登録されたフローを複製しても、複製されたフローはスケジューラーが登録されません。
* 複製されたフローは既存フローと完全に別々のフローです。

### フロー削除

フローメタデータを削除します。

* フローメタデータを完全に削除します。
* 削除されたフローは復旧できません。
* 実行中のフローは削除できません。

### もっと見る - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つのみ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始されます。
* 一度も保存せずに一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラーによって実行中でも、ユーザーによって開始されたフローと同様にフローを開始することはできません。

### もっと見る - フロー終了
* 実行準備中、実行中、ドレイニング中のフローを終了できます。
* 残りのイベントは処理せずに終了します。

### もっと見る - フロードレイニング後終了
* 実行中のフローをドレイニング後に終了できます。
* ドレイニングはフローの残りのイベントを処理することを意味します。
* タイムアウト時間を超過する場合、ドレイニングが終了していなくても終了されます。
* タイムアウト時間が残っている状態でドレイニングが終了する場合、すぐに終了されます。
* ドレイニング中のフローはフロー終了を通じてすぐに終了できます。
