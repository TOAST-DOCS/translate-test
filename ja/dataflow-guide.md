## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは、以下のような順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかどうかを確認します。

## 管理

フローのメタデータ情報を照会および管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定された基準によってフローを検索します。

* フロー名を基準に検索すると、名前に検索ワードが含まれたフローを検索します。

### フィルター

指定された条件によってフローを検索します。

* フロー状態値によるフィルタリングオプションを提供します。

### フロー一覧

照会結果をフロー表形式で表示します。

* 簡単なフロー メタデータと現在のフロー実行状態を表示します。
* 最後の修正日を基準に並べ替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルタリング条件機能を通じて特定の状態のフローのみ照会できます。
* 1度照会されたフローは**更新**を押す必要があり照会結果を更新します。
* 1ページあたり12個のフローを照会し、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態                                         | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害または認証不可などが原因でエラーが発生しました。継続的に<b>ERROR</b>が発生した場合は、**カスタマーサポート > 問い合わせ**でお問い合わせください。 |
| STOP\_FAILED   | フロー終了要求に失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行過程で未知の原因により エラーが発生しました。継続的に<b>UNKNOWN</b>が発生した場合は、**カスタマーサポート > 問い合わせ**でお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更されたときに通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフロー メタデータを作成します。
* フロー名は他のフローと重複することができます。
* フロー目的に応じた実行モードを選択します。
* フロー テンプレートを指定してユーザーが希望する機能のフローを簡単に読み込むことができます。
* フローを実行するためのインスタンス タイプを設定できます。 

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフロー メタデータに反映させます。
* フロー テンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フローを実行するためのインスタンス タイプを変更できます。
    * ただし、変更されたインスタンス タイプは次のフロー実行から適用されます。

### フロー複製

既存のフロー定義を持って新しいメタデータを作成します。

* 既存フローの名前に`_copy`文字が追加された新しいメタデータを作成します。
* 既存フローが持つフロー ロジックをそのままコピーしてきます。
* 実行中のフローもコピーが可能です。
* 実行中のフローは停止状態でコピーします。
* フローの現在の保存状態が一時保存である場合、既存フローの最後の保存バージョンはコピーしません。
* スケジューラが登録されたフローをコピーしても、コピーしたフローにはスケジューラが登録されません。
* コピーしたフローは既存フローと完全に別個のフローです。

### フロー削除

フロー メタデータを削除します。

* フロー メタデータを完全に削除します。
* 削除したフローは復旧できません。
* 実行中のフローは削除できません。

### その他 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つだけ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始します。
* 1度も保存せず一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラにより実行中でも、ユーザーにより開始したフローと同じようにフローを開始することはできません。

### その他 - フロー終了
* 実行準備中、実行中、またはドレイニング中のフローを終了できます。
* 残余イベントを処理せずに終了します。

### その他 - フロードレイニング後終了
* 実行中のフローをドレイニング後に終了できます。
* ドレイニングはフローの残余イベントを処理することを意味します。
* タイムアウト時間を超える場合、ドレイニングが終わらなくても終了します。
* タイムアウト時間が残っている状態でドレイニングが終了する場合、すぐに終了します。
* ドレイニング中のフローはフロー終了を通じてすぐに終了できます。
