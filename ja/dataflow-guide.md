## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは以下の順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかを確認します。

## 管理

フロー メタデータ情報を照会・管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定条件によってフローを検索します。

* フロー名を条件に検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

指定条件によってフローを検索します。

* フロー状態値に応じたフィルタリングオプションを提供します。

### フロー一覧

検索結果のフローをテーブル形式で表示します。

* 簡潔なフロー メタデータと現在のフロー実行状態を表示します。
* 最終変更日を基準に並び替えます。
* フローを選択して、フロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定状態のフローのみ照会できます。
* 一度照会されたフローは、**更新**ボタンを押して照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会し、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態 | 説明 |
|---| --- |
| START_FAILED  | フロー実行リクエストに失敗しました。 |
| QUOTA_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などでエラーが発生しました。継続的に<b>ERROR</b>が発生する場合は、**カスタマーサポート > お問い合わせ**からお問い合わせください。 |
| STOP_FAILED   | フロー終了リクエストに失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレーニング中です。 |
| UNKNOWN            | フロー実行過程で不明な原因によるエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は、**カスタマーサポート > お問い合わせ**からお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更された場合、通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のため名前と説明を追加してフロー メタデータを作成します。
* フロー名は他のフローと重複が可能です。
* フロー目的に応じた実行モードを選択します。
* フロー テンプレートを指定してユーザーが希望する機能のフローを簡単に読み込むことができます。
* フロー実行のためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフロー メタデータに反映します。
* フロー テンプレートは指定できません。
* フロー実行中もフロー変更が可能です。
* フロー実行のためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次回フロー実行から適用されます。

### フロー複製

既存のフロー定義を持って新しいメタデータを作成します。

* 既存フローの名前に`_copy`文字列が追加された新しいメタデータを作成します。
* 既存フローが持つフロー ロジックをそのままコピーします。
* 実行中のフローも複製が可能です。
* 実行中のフローは停止状態で複製します。
* フローの現在の保存状態が仮保存である場合、既存フローの最後の保存版は複製しません。
* スケジューラーが登録されているフローを複製しても、複製されたフローにはスケジューラーが登録されません。
* 複製されたフローは既存フローと完全に別個のフローです。

### フロー削除

フロー メタデータを削除します。

* フロー メタデータを完全に削除します。
* 削除されたフローは復元できません。
* 実行中のフローは削除できません。

### 詳細 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つのみ実行できます。
* 仮保存されたフローは最後に保存されたバージョンで開始します。
* まだ1度も保存せず仮保存のみされたフローは開始できません。
* フローは必ず1回以上保存する必要があります。
* フローがスケジューラーにより実行中でも、ユーザーにより開始されたフローと同様にフローを開始できません。

### 詳細 - フロー終了
* 実行準備中または実行中、ドレーニング中のフローを終了できます。
* 残りのイベントは処理せず終了します。

### 詳細 - フロードレーニング後終了
* 実行中のフローをドレーニング後に終了できます。
* ドレーニングはフローの残りイベントを処理することを意味します。
* タイムアウト時間を超過する場合、ドレーニングが終了していなくても終了します。
* タイムアウト時間が残っている状態でドレーニングが終了する場合は、即座に終了します。
* ドレーニング中のフローはフロー終了を通じて即座に終了できます。
