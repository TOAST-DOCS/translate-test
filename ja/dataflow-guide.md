## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlow は次の手順で使用できます。

* サービスの有効化
    1. プロジェクトを作成します。
    2. 使用するプロジェクトを選択します。
    3. DataFlow サービスを有効化します。
* フローの実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続によってノードの動作順序を決定し、フローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認して、フローが正常に実行されたことを確認します。

## 管理

フローのメタデータ情報を照会・管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](https://static.toastoven.net/prod2_translate-test/ja/management_main_2025_06.png)

### 検索

指定した条件でフローを検索します。

* フロー名を基準に検索すると、名前に検索キーワードが含まれるフローを検索します。

### フィルタ

指定した条件でフローを検索します。

* フローのステータス値に基づくフィルタリングオプションを提供します。

### フロー一覧

照会結果のフローをテーブル形式で表示します。

* フローの基本的なメタデータと現在のフロー実行状態を表示します。
* 最終更新日を基準に並べ替えます。
* フローを選択して、フロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルタ条件機能を使用して、特定の状態のフローのみ照会できます。
* 一度照会したフローは、**更新**をクリックしないと照会結果が更新されません。
* 1ページあたり12件のフローを表示し、**前へ**および**次へ**をクリックしてページを移動できます。

#### フローステータス情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED | フローの実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行に必要なリソースが不足しているため、実行に失敗しました。 |
| STARTING | フロー実行に必要なリソースを確保しています。 |
| PREPARING | フロー実行の準備が完了しました。 |
| RUNNING | フローが実行中です。 |
| ERROR | フローの実行中に通信障害や認証不可などによりエラーが発生しました。継続的に <b>ERROR</b> が発生する場合は、**カスタマーサポート > お問い合わせ**よりお問い合わせください。 |
| STOP\_FAILED | フローの終了要求に失敗しました。 |
| STOPPED | フローが終了しました。 |
| DRAINING | フローがドレイン中です。 |
| UNKNOWN | フローの実行中に不明な原因によりエラーが発生しました。継続的に <b>UNKNOWN</b> が発生する場合は、**カスタマーサポート > お問い合わせ**よりお問い合わせください。 |

#### フローステータス変更通知メール
* 通知対象のフローステータスに変更された際に、通知メールを受信できます。
* 通知対象のフローステータス
    * RUNNING
    * ERROR
    * STOPPED
* デフォルトの受信対象
    * 使用中の DataFlow サービスが有効化されているプロジェクトで **DataFlow ADMIN** ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フローを識別するために名前と説明を追加して、フローのメタデータを作成します。
* フロー名は他のフローと重複することができます。
* フローの目的に応じた実行モードを選択します。
* フローテンプレートを指定することで、ユーザーが必要な機能のフローを手軽に読み込めます。
* フローを実行するためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正して、フローのメタデータに反映します。
* フローテンプレートは指定できません。
* フローの実行中もフローの変更が可能です。
* フローを実行するためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次回のフロー実行から適用されます。

### フローコピー

既存のフロー定義を使用して新しいメタデータを作成します。

* 既存のフロー名に `_copy` が追加された新しいメタデータを作成します。
* 既存フローが持つフローロジックをそのままコピーします。
* 実行中のフローもコピーできます。
* 実行中のフローは停止状態でコピーします。
* フローの現在の保存状態が一時保存の場合、既存フローの最後の保存バージョンはコピーしません。
* スケジューラーが登録されているフローをコピーしても、コピーしたフローにはスケジューラーが登録されません。
* コピーしたフローは既存フローとは完全に別個のフローです。

### フロー削除

フローのメタデータを削除します。

* フローのメタデータを完全に削除します。
* 削除したフローは復旧できません。
* 実行中のフローは削除できません。

### さらに表示 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つのみ実行できます。
* 一時保存したフローは、最後に保存したバージョンで開始します。
* 一度も保存せずに一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラーによって実行中であっても、ユーザーによって開始したフローと同様に、フローを開始することはできません。

### さらに表示 - フロー終了
* 実行準備中、実行中、またはドレイン中のフローを終了できます。
* 残余イベントは処理せずに終了します。

### さらに表示 - フローをドレイン後に終了
* 実行中のフローをドレイン後に終了できます。
* ドレインとは、フローの残余イベントを処理することを意味します。
* タイムアウト時間を超過した場合、ドレインが完了していなくても終了します。
* タイムアウト時間が残っている状態でドレインが完了した場合は、即座に終了します。
* ドレイン中のフローは、フロー終了を使用してすぐに終了できます。
