## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは以下の順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 希望するプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通してノードの動作順序を決定してフローを完成します。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかを確認します。

## 管理

フローメタデータ情報を照会して管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](https://static.toastoven.net/prod_translate/ja/management_main_2025_06.png)

### 検索

指定した基準でフローを検索します。

* フロー名を基準に検索すると、名前に検索語が含まれているフローを検索します。

### フィルター

指定した条件でフローを検索します。

* フロー状態値によるフィルタリングオプションを提供します。

### フローリスト

照会結果フローをテーブル形式で表示します。

* 簡単なフローメタデータと現在のフロー実行状態を表示します。
* 最近修正日を基準に並び替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通して特定状態のフローのみ照会できます。
* 一度照会されたフローは**更新**を押さないと照会結果が更新されません。
* 1ページあたり12個のフローを照会し、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー状態情報

| フロー実行状態                                         | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などによってエラーが発生しました。継続的に<b>ERROR</b>が発生する場合は**お客様サポート > お問い合わせ**でお問い合わせください。 |
| STOP\_FAILED   | フロー終了要求に失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行過程で不明な原因によってエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は**お客様サポート > お問い合わせ**でお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更された時に通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**役割を持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフローメタデータを作成します。
* フロー名は他のフローと重複が可能です。
* フロー目的による実行モードを選択します。
* フローテンプレートを指定してユーザーが希望する機能のフローを簡単に呼び出すことができます。
* フローを実行するためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフローメタデータに反映します。
* フローテンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フローを実行するためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複写

既存のフロー定義を持って新しいメタデータを作成します。

* 既存フローの名前に`_copy`文句が追加された新しいメタデータを作成します。
* 既存フローが持つフローロジックをそのまま複写してきます。
* 実行中のフローも複写が可能です。
* 実行中のフローは停止状態で複写します。
* フローの現在保存状態が一時保存であれば、既存フローの最後の保存バージョンは複写しません。
* スケジューラが登録されたフローを複写しても、複写したフローはスケジューラが登録されません。
* 複写したフローは既存フローと完全に別のフローです。

### フロー削除

フローメタデータを削除します。

* フローメタデータを完全に削除します。
* 削除したフローは復旧できません。
* 実行中のフローは削除できません。

### その他 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つだけ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始します。
* 一度も保存せずに一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存しないと開始できません。
* フローがスケジューラによって実行中でも、ユーザーによって開始したフローと同じくフローを開始できません。

### その他 - フロー終了
* 実行準備中、実行中、ドレイニング中のフローを終了できます。
* 残余イベントは処理せずに終了します。

### その他 - フロードレイニング後終了
* 実行中のフローをドレイニング後終了できます。
* ドレイニングはフローの残余イベントを処理することを意味します。
* タイムアウト時間を超過した場合、ドレイニングが終わらなくても終了します。
* タイムアウト時間が残っている状態でドレイニングが終わった場合、すぐに終了します。
* ドレイニング中のフローはフロー終了を通してすぐに終了できます。
