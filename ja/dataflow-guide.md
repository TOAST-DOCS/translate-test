## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlow は次の手順で使用できます。

* サービスの有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlow サービスを有効にします。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかどうかを確認します。

## 管理

フロー メタデータ情報を照会および管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定された基準でフローを検索します。

* フロー名を基準に検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

指定された条件でフローを検索します。

* フロー状態値に基づくフィルターオプションを提供します。

### フロー一覧

照会結果のフローをテーブル形式で表示します。

* 簡潔なフロー メタデータと現在のフロー実行状態を表示します。
* 最終更新日を基準にソートします。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定の状態のフローのみ照会できます。
* 一度照会されたフローは、**[更新]**をクリックして照会結果を更新する必要があります。
* 1 ページあたり 12 個のフローを照会し、**[前へ]**および**[次へ]**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行リクエストに失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足してクエストに失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行プロセス中に通信障害または認証不可などのエラーが発生しました。継続的に<b>ERROR</b>が発生する場合は、**カスタマーサポート > お問い合わせ**にお問い合わせください。 |
| STOP\_FAILED   | フロー終了リクエストに失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレイン中です。 |
| UNKNOWN            | フロー実行プロセス中に未知の原因によってエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は、**カスタマーサポート > お問い合わせ**にお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更されると、通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中の DataFlow サービスが有効化されているプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フロー定義するメタデータを作成します。

* フロー識別のため名前と説明を追加してフロー メタデータを作成します。
* フロー名は他のフローと重複が可能です。
* フロー目的に基づいて実行モードを選択します。
* フロー テンプレートを指定してユーザーが目的の機能のフローを簡単に読み込むことができます。
* フロー実行のためのインスタンスタイプを設定できます。 

### フロー変更

フロー メタデータを修正します。

* 既存のフロー名と説明を修正してフロー メタデータに反映します。
* フロー テンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フロー実行のためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複製

既存のフロー定義を持つ新しいメタデータを作成します。

* 既存フローの名前に`_copy`テキストが追加された新しいメタデータを作成します。
* 既存フローが持つフロー ロジックをそのままコピーしてきます。
* 実行中のフローも複製が可能です。
* 実行中のフローは停止状態で複製します。
* フローの現在の保存状態が一時保存の場合、既存フローの最後の保存バージョンは複製しません。
* スケジューラが登録されているフローを複製しても、複製されたフローにはスケジューラが登録されません。
* 複製されたフローは既存フローと完全に別個のフローです。

### フロー削除

フロー メタデータを削除します。

* フロー メタデータを完全に削除します。
* 削除されたフローは復元できません。
* 実行中のフローは削除できません。

### その他 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に 1 つだけ実行できます。
* 一時保存されたフローは最後に保存したバージョンで開始します。
* 一度も保存せず一時保存のみしたフローは開始できません。
* フローは必ず 1 回以上保存してから開始できます。
* フローがスケジューラによって実行中であっても、ユーザーによって開始されたフローと同じようにフローを開始できません。

### その他 - フロー終了
* 実行準備中、実行中、またはドレイン中のフローを終了できます。
* 残留イベントは処理せずに終了します。

### その他 - フロードレイン後に終了
* 実行中のフローをドレイン後に終了できます。
* ドレインはフローの残留イベントを処理することを意味します。
* タイムアウト時間を超過する場合、ドレインが終了していなくても終了します。
* タイムアウト時間が残った状態でドレインが終了する場合、すぐに終了します。
* ドレイン中のフローはフロー終了を通じてすぐに終了できます。
