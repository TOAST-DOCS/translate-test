## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは、以下の順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認して、フローが正常に実行されたかを確認します。

## 管理

フローのメタデータ情報を照会し、管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定された基準でフローを検索します。

* フロー名を基準に検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

指定された条件でフローを検索します。

* フロー状態値に基づくフィルタリングオプションを提供します。

### フロー一覧

照会結果をテーブル形式でフローを表示します。

* 簡単なフローメタデータと現在のフロー実行状態を表示します。
* 最近の修正日を基準に並べ替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定の状態のフローのみ照会できます。
* 一度照会されたフローは、**更新**を押して照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会し、**前**および**次**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行リクエストに失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などのため、エラーが発生しました。継続的に<b>ERROR</b>が発生する場合は、**カスタマーサポート > お問い合わせ**にお問い合わせください。 |
| STOP\_FAILED   | フロー終了リクエストに失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行過程で不明な原因によってエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は、**カスタマーサポート > お問い合わせ**にお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象のフロー状態に変更されたときに通知メールを受け取ることができます。
* 通知対象のフロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されているプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフローメタデータを作成します。
* フロー名は他のフローと重複可能です。
* フロー目的に応じた実行モードを選択します。
* フローテンプレートを指定してユーザーが望む機能のフローを簡単に読み込むことができます。
* フロー実行のためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフローメタデータに反映します。
* フローテンプレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フロー実行のためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複製

既存のフロー定義を基に新しいメタデータを作成します。

* 既存フローの名前に`_copy`文字列が追加された新しいメタデータを作成します。
* 既存フローが持つフロープロジェクトをそのままコピーします。
* 実行中のフローも複製が可能です。
* 実行中のフローは停止状態で複製します。
* フローの現在の保存状態が一時保存の場合、既存フローの最後の保存バージョンは複製しません。
* スケジューラが登録されたフローを複製しても、複製したフローにはスケジューラが登録されません。
* 複製したフローは、既存フローと完全に独立したフローです。

### フロー削除

フローメタデータを削除します。

* フローメタデータを完全に削除します。
* 削除されたフローは復旧できません。
* 実行中のフローは削除できません。

### 詳細表示 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つだけ実行できます。
* 一時保存されたフローは最後に保存したバージョンで開始します。
* 一度も保存しないで一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラによって実行中であっても、ユーザーによって開始したフローと同じようにフローを開始できません。

### 詳細表示 - フロー終了
* 実行準備中または実行中、ドレイニング中のフローを終了できます。
* 残りのイベントは処理せずに終了します。

### 詳細表示 - フロードレイニング後終了
* 実行中のフローをドレイニング後に終了できます。
* ドレイニングはフローの残りのイベントを処理することを意味します。
* タイムアウト時間を超過した場合、ドレイニングが終了していなくても終了します。
* タイムアウト時間が残っている状態でドレイニングが終了した場合、すぐに終了します。
* ドレイニング中のフローはフロー終了を通じてすぐに終了できます。
