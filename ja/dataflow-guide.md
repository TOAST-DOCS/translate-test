## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは以下の順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定し、フローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたかどうかを確認します。

## 管理

フローメタデータ情報を照会および管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

与えられた基準でフローを検索します。

* フロー名を基準に検索すると、名前に検索語が含まれるフローを検索します。

### フィルター

与えられた条件でフローを検索します。

* フロー状態値に基づくフィルタリングオプションを提供します。

### フロー一覧

照会結果をテーブル形式でフローを表示します。

* 簡単なフローメタデータと現在のフロー実行状態を表示します。
* 最終修正日を基準に並べ替えます。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を通じて特定の状態のフローのみ照会できます。
* 一度照会されたフローは**更新**を押して照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会し、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行リクエストに失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足して実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フロー実行中です。 |
| ERROR              | フロー実行過程で通信障害や認証不可などによってエラーが発生しました。継続的に<b>ERROR</b>が発生する場合は**カスタマーサポート > お問い合わせ**からお問い合わせください。 |
| STOP\_FAILED   | フロー終了リクエストに失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フロー過程中です。 |
| UNKNOWN            | フロー実行過程で原因不明のエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は**カスタマーサポート > お問い合わせ**からお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更されたときに通知メールを受け取ることができます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルト受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**ロールを持つメンバー

### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフローメタデータを作成します。
* フロー名は他のフローと重複可能です。
* フロー目的に応じた実行モードを選択します。
* フロー テンプレートを指定して、ユーザーが必要とする機能のフローを簡単に読み込むことができます。
* フロー実行のためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフローメタデータに反映します。
* フロー テンプレートは指定できません。
* フロー実行中もフロー変更が可能です。
* フロー実行のためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複写

既存のフロー定義を持つ新しいメタデータを作成します。

* 既存フローの名前に`_copy`文字列が追加された新しいメタデータを作成します。
* 既存フローが持つフロー論理をそのままコピーします。
* 実行中のフローもコピー可能です。
* 実行中のフローは停止状態でコピーします。
* フローの現在保存状態が一時保存の場合は既存フローの最後の保存バージョンはコピーしません。
* スケジューラが登録されたフローをコピーしても、コピーしたフローはスケジューラが登録されません。
* コピーしたフローは既存フローと完全に別のフローです。

### フロー削除

フローメタデータを削除します。

* フローメタデータを完全に削除します。
* 削除したフローは復構できません。
* 実行中のフローは削除できません。

### その他 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つのみ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始します。
* 一度も保存せず一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存してから開始できます。
* フローがスケジューラによって実行中でも、ユーザーによって開始したフローと同じようにフローを開始できません。

### その他 - フロー終了
* 実行準備中、実行中、またはドレイニング中のフローを終了できます。
* 残りのイベントは処理せずに終了します。

### その他 - フロードレイニング後の終了
* 実行中のフローをドレイニング後に終了できます。
* ドレイニングはフローの残りのイベントを処理することを意味します。
* タイムアウト時間を超える場合、ドレイニングが終わらなくても終了します。
* タイムアウト時間が残っている状態でドレイニングが終わる場合は、すぐに終了します。
* ドレイニング中のフローはフロー終了を通じてすぐに終了できます。
