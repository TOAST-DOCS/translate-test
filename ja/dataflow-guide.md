## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlow は次の手順で使用できます。

* サービスの有効化
    1. プロジェクトを作成します。
    2. 使用するプロジェクトを選択します。
    3. DataFlow サービスを有効化します。
* フローの実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方法を定義します。
    3. ノードを接続してノードの動作順序を決定し、フローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認して、フローが正常に実行されたかどうかを確認します。

## 管理

フローのメタデータ情報を照会および管理するページです。
**Data & Analytics > DataFlow > 管理** をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定した条件でフローを検索します。

* フロー名を基準に検索すると、名前に検索キーワードが含まれるフローを検索します。

### フィルター

指定した条件でフローを検索します。

* フロー状態値によるフィルタリングオプションを提供します。

### フロー一覧

照会結果のフローをテーブル形式で表示します。

* フローの簡単なメタデータと現在のフロー実行状態を表示します。
* 最終更新日を基準に並べ替えます。
* フローを選択して、フローの変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルター条件機能を使用して、特定の状態のフローのみを照会できます。
* 一度照会したフローは、**[更新]** をクリックしないと照会結果が更新されません。
* 1 ページあたり 12 個のフローを照会し、**[前へ]** および **[次へ]** をクリックしてページを移動できます。

#### フロー状態情報

| フロー実行状態                                         | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行に必要なリソースが不足しているため、実行に失敗しました。 |
| STARTING       | フロー実行に必要なリソースを確保しています。 |
| PREPARING      | フロー実行の準備が完了しました。 |
| RUNNING        | フローを実行中です。 |
| ERROR              | フローの実行中に通信障害や認証エラーなどによりエラーが発生しました。継続的に <b>ERROR</b> が発生する場合は、**[カスタマーサポート] > [お問い合わせ]** からお問い合わせください。 |
| STOP\_FAILED   | フロー停止要求に失敗しました。 |
| STOPPED        | フローが停止しました。 |
| DRAINING       | フローがドレイン中です。 |
| UNKNOWN            | フローの実行中に不明な原因によりエラーが発生しました。継続的に <b>UNKNOWN</b> が発生する場合は、**[カスタマーサポート] > [お問い合わせ]** からお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象のフロー状態に変更された場合に、通知メールを受信できます。
* 通知対象のフロー状態
    * RUNNING
    * ERROR
    * STOPPED
* デフォルトの受信対象
    * 使用中の DataFlow サービスが有効化されているプロジェクトで **DataFlow ADMIN** ロールを持つメンバー


### フローの作成

フローを定義するメタデータを作成します。

* フローを識別するために名前と説明を追加して、フローのメタデータを作成します。
* フロー名は他のフローと重複可能です。
* フローの目的に応じた実行モードを選択します。
* フローテンプレートを指定して、ユーザーが希望する機能のフローを簡単に読み込むことができます。
* フローを実行するためのインスタンスタイプを設定できます。

### フローの変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正して、フローのメタデータに反映します。
* フローテンプレートは指定できません。
* フローの実行中でもフローの変更が可能です。
* フローを実行するためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次回のフロー実行から適用されます。

### フローのコピー

既存のフロー定義を使用して新しいメタデータを作成します。

* 既存のフロー名に `_copy` 文字列が追加された新しいメタデータを作成します。
* 既存のフローが持つフローロジックをそのままコピーします。
* 実行中のフローもコピーできます。
* 実行中のフローは停止状態でコピーします。
* フローの現在の保存状態が一時保存の場合、既存のフローの最終保存バージョンはコピーされません。
* スケジューラーが登録されているフローをコピーしても、コピーされたフローにはスケジューラーが登録されません。
* コピーされたフローは、既存のフローとは完全に独立したフローです。

### フローの削除

フローのメタデータを削除します。

* フローのメタデータを完全に削除します。
* 削除したフローは復元できません。
* 実行中のフローは削除できません。

### その他 - フローの開始
停止状態のフローを開始します。

* 各フローは同時に 1 つのみ実行できます。
* 一時保存したフローは、最後に保存したバージョンで開始します。
* 一度も保存せず一時保存のみを行ったフローは開始できません。
* フローは必ず 1 回以上保存してから開始できます。
* フローがスケジューラーによって実行中であっても、ユーザーによって開始したフローと同様にフローを開始することはできません。

### その他 - フローの停止
* 実行準備中、実行中、またはドレイン中のフローを停止できます。
* 残余イベントは処理せずに停止します。

### その他 - フローのドレイン後に停止
* 実行中のフローをドレイン後に停止できます。
* ドレインとは、フローの残余イベントを処理することを意味します。
* タイムアウト時間を超過した場合、ドレインが完了していなくても停止します。
* タイムアウト時間が残っている状態でドレインが完了した場合、すぐに停止します。
* ドレイン中のフローは、フロー停止機能を使用してすぐに停止できます。
