## Data & Analytics > DataFlow > コンソール使用ガイド

DataFlowは次のような順序で使用できます。

* サービス有効化
    1. プロジェクトを作成します。
    2. 目的のプロジェクトを選択します。
    3. DataFlowサービスを有効化します。
* フロー実行
    1. フローを作成します。
    2. 必要なノードを追加し、設定値を入力して各ノードの動作方式を定義します。
    3. ノード接続を通じてノードの動作順序を決定してフローを完成させます。
    4. フローを実行します。
    5. ログ情報を確認してフローが正常に実行されたか確認します。

## 管理

フローのメタデータ情報を照会し、管理するページです。
**Data & Analytics > DataFlow > 管理**をクリックします。

![management_main.png](http://static.toastoven.net/prod_dataflow/ko/console_user_guide/management_main_2025_06.png)

### 検索

指定された基準でフローを検索します。

* フロー名に基づいて検索する場合、名前に検索語が含まれるフローを検索します。

### フィルタ

指定された条件でフローを検索します。

* フロー状態値に基づくフィルタリングオプションを提供します。

### フロー一覧

照会結果をテーブル形式でフローを表示します。

* シンプルなフローメタデータと現在のフロー実行状態を表示します。
* 最近修正日に基づいてソートします。
* フローを選択してフロー変更、フロー詳細表示、フロー開始などの管理機能を使用できます。
* フィルタ条件機能を通じて特定状態のフローのみ照会できます。
* 一度照会されたフローは**リフレッシュ**を押して照会結果を更新する必要があります。
* 1ページあたり12個のフローを照会でき、**前へ**および**次へ**をクリックしてページを移動できます。

#### フロー実行状態情報

| フロー実行状態 | 説明 |
|---------------------------------------------------| --- |
| START\_FAILED  | フロー実行要求に失敗しました。 |
| QUOTA\_EXCEEDED | フロー実行のためのリソースが不足し実行に失敗しました。 |
| STARTING       | フロー実行のためのリソースを確保中です。 |
| PREPARING      | フロー実行準備が完了しました。 |
| RUNNING        | フローが実行中です。 |
| ERROR              | フロー実行中に通信障害や認証不可などでエラーが発生しました。継続的に<b>ERROR</b>が発生する場合は**カスタマーサポート > お問い合わせ**からお問い合わせください。 |
| STOP\_FAILED   | フロー終了要求に失敗しました。 |
| STOPPED        | フローが終了しました。 |
| DRAINING       | フローがドレイニング中です。 |
| UNKNOWN            | フロー実行中に不明な原因でエラーが発生しました。継続的に<b>UNKNOWN</b>が発生する場合は**カスタマーサポート > お問い合わせ**からお問い合わせください。 |

#### フロー状態変更通知メール
* 通知対象フロー状態に変更されたときに通知メールを受信できます。
* 通知対象フロー状態
    * RUNNING
    * ERROR
    * STOPPED
* 基本受信対象
    * 使用中のDataFlowサービスが有効化されたプロジェクトの**DataFlow ADMIN**ロールを持つメンバー


### フロー作成

フローを定義するメタデータを作成します。

* フロー識別のために名前と説明を追加してフローメタデータを作成します。
* フロー名は他のフローと重複可能です。
* フロー目的に応じた実行モードを選択します。
* フロー템プレートを指定してユーザーが望む機能のフローを簡単に呼び出すことができます。
* フロー実行のためのインスタンスタイプを設定できます。

### フロー変更

フローのメタデータを修正します。

* 既存のフロー名と説明を修正してフローメタデータに反映します。
* フロー템プレートは指定できません。
* フロー実行中でもフロー変更が可能です。
* フロー実行のためのインスタンスタイプを変更できます。
    * ただし、変更されたインスタンスタイプは次のフロー実行から適用されます。

### フロー複製

既存のフロー定義を使用して新しいメタデータを作成します。

* 既存フローの名前に`_copy`文言が追加された新しいメタデータを作成します。
* 既存フローが持つフロー論理をそのまま複製します。
* 実行中のフローも複製可能です。
* 実行中のフローは停止状態で複製します。
* フローの現在の保存状態が一時保存の場合、既存フローの最後の保存バージョンは複製しません。
* スケジューラが登録されたフローを複製しても、複製したフローにはスケジューラが登録されません。
* 複製したフローは既存フローと完全に別個のフローです。

### フロー削除

フローメタデータを削除します。

* フローメタデータを完全に削除します。
* 削除したフローは復旧できません。
* 実行中のフローは削除できません。

### 詳細 - フロー開始
停止状態のフローを開始します。

* 各フローは同時に1つだけ実行できます。
* 一時保存したフローは最後に保存したバージョンで開始します。
* 一度も保存せず一時保存のみしたフローは開始できません。
* フローは必ず1回以上保存する必要があります。
* フローがスケジューラによって実行中でも、ユーザーによって開始したフローと同じようにフローを開始することはできません。

### 詳細 - フロー終了
* 実行準備中、実行中、またはドレイニング中のフローを終了できます。
* 残存イベントは処理せずに終了します。

### 詳細 - フロードレイニング後の終了
* 実行中のフローをドレイニング後に終了できます。
* ドレイニングは、フローの残存イベントを処理することを意味します。
* タイムアウト時間を超えた場合、ドレイニングが終わらなくても終了します。
* タイムアウト時間が残っている状態でドレイニングが終わった場合、すぐに終了します。
* ドレイニング中のフローはフロー終了により直ちに終了できます。
