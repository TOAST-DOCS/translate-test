## Database > RDS for MariaDB > リリースノート

## 2026. 07. 14.

### 機能追加及び改善

* MariaDB 10.11.18、11.4.12、11.8.8バージョンを追加

### バグ修正

* セキュリティパッチ対象の単一インスタンスを高可用性インスタンスに変更した際にセキュリティパッチが実行されない問題を修正

## 2026. 05. 12.

### 機能追加及び改善

* セキュリティパッチ機能を追加
    * OSで発見されたセキュリティ脆弱性(CVE)に対するセキュリティパッチをメンテナンス作業として実行できます。
    * 詳細については、[セキュリティパッチ](/Database/RDS%20for%20MariaDB/ja/db-instance/#security-patch)のドキュメントを参照してください。
* 高可用性Pingチェック方式に既存の`INSERT`以外に`SELECT`オプションを追加
* MariaDB 10.6.25、10.11.16、11.4.10、11.8.6バージョンを追加
* MariaDB 10.3、10.6のEOL(End of Life)に伴う新規作成の制限
* API v4.0の追加および変更
    * 高可用性情報表示APIが追加されます。

### 2026. 03. 10.

#### 機能追加及び改善

* API v4.0を追加
    * 詳細については、[API v4.0ガイド](/Database/RDS%20for%20MariaDB/ja/api-guide-v4.0/)のドキュメントを参照してください。
* スナップショットバックアップ機能を追加
    * CinderストレージのスナップショットをDBパフォーマンスに影響を与えずにバックアップを実行

* DBスキーマ＆ユーザー直接制御設定時にROLE_ADMIN権限も付与するよう修正

### 2025. 11. 11.

#### 機能追加及び改善

- Lock取得失敗によるバックアップ失敗時に原因をイベントに記録するよう改善

#### バグ修正

- フェイルオーバー失敗時に「フェイルオーバー中」の状態が継続する問題を修正
- 7月のデプロイ以前に停止したDBインスタンスを起動できない問題を修正
- リードレプリカのみ別のパラメータグループを使用している場合、複数のDBインスタンスを選択後に最新のパラメータグループを適用できない問題を修正
- パラメータグループの再設定時に変更不可の値が変更される現象を修正

### 2025. 09. 09.

#### 機能追加及び改善

- MariaDB 10.6.22、10.11.13、11.4.7バージョンを追加

#### バグ修正

- 既に作成された高可用性インスタンスをクリック後、高可用性インスタンス作成時に予備マスター名が入力された状態で表示される現象を修正
- 高可用性に追加されたリードレプリカ名を修正できない現象を修正
- DBインスタンスへのVIP追加が不可能な状況でドロップダウンメニューの[VIP追加]メニューが有効になる現象を修正
- DHCP更新失敗時に内部IPが断続的に消える現象を修正
- 高可用性インスタンスへのリードレプリカ作成中に失敗した場合、高可用性が停止する現象を修正
- 同じ組織でサブスクライブしたイベントが複数発生した場合、サブスクリプション通知が動作しない現象を修正

### 2023. 05. 16.

#### 機能追加及び改善

* サービスのユーザーインターフェース(UI)をNHN Cloud全サービスと一貫性が保たれるよう改善
* DBインスタンスが削除されても手動バックアップは削除されないよう修正
* パラメータグループ機能を追加
    * DBインスタンスのデータベース設定を自由に変更できるようサポート
    * 複数のDBインスタンスに適用可能
    * 既存DBインスタンスの設定変更内容はDBインスタンスと同名のパラメータグループへマイグレーション
* DBセキュリティグループ機能を追加
    * DBインスタンスのアクセス制御を自由に設定できるようサポート
    * 複数のDBインスタンスに適用可能
    * 既存DBインスタンスに設定されたアクセス制御ルールは`{DBインスタンス名}__{DBインスタンスID}`のルールで命名されたDBセキュリティグループへマイグレーション
* 複製関係に応じてDBインスタンスをグループ化して表示できる画面を提供
* コンソールに予備マスターを表示
    * 予備マスターのバイナリログ(binary log)を削除して容量を確保可能
    * 予備マスターの各種ログの確認およびダウンロードをサポート
* リードレプリカ再構築をサポート
    * リードレプリカのDBインスタンスは変更されないため、固定IPアドレスは変更されません。
    * データベースのデータはすべて削除され、マスターのデータで復旧されます。
* フェイルオーバーしたマスターの復旧をサポート
    * フェイルオーバーしたマスターと新規マスターを高可用性構成で復旧可能
    * 復旧は失敗する可能性があり、復旧できないフェイルオーバーしたマスターは再構築可能
* フェイルオーバーしたマスターの再構築をサポート
    * フェイルオーバーしたマスターのDBインスタンスは変更されないため、固定IPアドレスは変更されません。
    * データベースのデータはすべて削除され、マスターのデータで復旧されます。
* MySQL 8.0.32バージョンを追加
