## 異常検知

**Monitoring > Cloud Monitoring > 異常検知**は、Cloud Monitoring が収集した指標パターンを学習し、平常時と異なる異常兆候を自動的に検知します。

しきい値を手動で設定する必要がある通常のアラートとは異なり、異常検知は指標の過去のパターンを基準として、**Score** と **Score しきい値**を各時点で自動的に計算します。Score と Score しきい値はいずれも 0〜100 の範囲の値であり、Score が Score しきい値を超えた場合に異常状態と判断します。

異常検知は次の手順で使用します。

1. 異常検知の対象となる指標とリソースを選択し、異常検知項目を作成します。
2. ウィジェットチャートで Score と Score しきい値を確認し、異常発生区間を確認します。
3. 異常検知アラートを設定することで、異常発生時にアラートを受信できます。

!!! tip "ヒント"
    作成した異常検知項目は 1 分周期で評価されます。

### 異常検知の作成

**[異常検知の作成]** をクリックすると、異常検知作成画面に移動します。異常検知のサービスと対象を選択して作成できます。

- **[サービス]**: 異常検知をサポートする NHN Cloud サービスのみ表示され、単一選択のみ可能です。
- **[対象]**: 以下の項目の順序で設定します。
  - **[タイプ]**: サービスの指標タイプを選択します。
  - **[指標項目]**: 選択したタイプに属する指標項目が表示され、複数選択できます。指標項目ごとに選択したリソース数が合わせて表示されます。
  - **[リソース]**: NHN Cloud 内に作成されたリソースのうち、該当するタイプ/指標項目に属するリソースが表示され、複数選択できます。

選択した指標項目とリソースの組み合わせごとに異常検知項目が 1 件ずつ作成され、異常検知名は選択した指標項目とリソースを基準に自動生成されます。

すでに作成済みの組み合わせでは追加作成できません。該当する場合は **[作成済み]** と表示されます。

**[作成項目のプレビュー]** で、作成される異常検知項目の名前、指標、リソースを表で事前に確認できます。
**[作成]** が完了すると、プレビューに表示された項目がそれぞれ個別の異常検知項目として作成されます。このとき、作成直後に該当項目のアラート設定画面に移動するかどうかを選択できます。

!!! danger "注意"
    作成は全件成功または全件失敗として処理されます。
    選択した項目のうち 1 件でも作成できない項目があった場合、どの項目も作成されません。

異常検知作成直後の状態は **[有効化-待機]** であり、異常検知のための学習および推論が完了すると **[有効化-正常]** 状態に変更されます。状態が有効化-正常に変更されるまでは、チャートに Score と Score しきい値が表示されない場合があります。
詳細については、下記の **異常検知の状態** を参照してください。

### 異常検知一覧

異常検知画面は、左側の一覧エリアと右側のダッシュボードエリアで構成されます。一覧の異常検知項目が、右側のダッシュボードにそれぞれ 1 つのウィジェットとして表示されます。

一覧の各項目では、異常検知名、サービス、作成日時、状態情報を確認できます。項目のチェックボックスは、削除など複数の項目を一括処理する際に使用します。

- フィルター、並び替え、検索は左側の一覧と右側のダッシュボードエリアに同時に適用されます。
- **[フィルター]**: サービスと対象のフィルターで、一覧とダッシュボードに表示する項目を絞り込めます。フィルターは作成済みの異常検知項目を基準に構成されます。たとえば、Instance サービスの項目のみ存在する場合、サービスフィルターには Instance のみ表示されます。
- **[並び替え]**: 最新順または古い順で並び替えできます。
- **[検索]**: 異常検知名で検索できます。


### 異常検知ダッシュボード

異常検知ダッシュボードには、作成されたすべての異常検知項目が個別のウィジェットとして自動的に構成されます。

- **[有効化（正常）状態のみ表示]** を選択すると、**[有効化-正常]** 状態の項目のウィジェットのみ表示されます。
- **[ウィジェットデータのダウンロード]** から、ダッシュボードに表示されたウィジェットデータを .csv または .xlsx ファイルでダウンロードできます。

!!! tip "ヒント"
    異常検知ダッシュボードだけでなく、ダッシュボードタブで直接構成したダッシュボードにも異常検知ウィジェットを追加できます。

#### 異常検知ウィジェットチャート

ウィジェットチャートには次の要素が合わせて表示されます。

- **[指標値]**: 異常検知の対象として選択した指標の実際の収集値です。左側の Y 軸を基準に表示されます。
- **[Score]**: 現在のデータが過去のパターンから逸脱した程度を 0〜100 に換算した数値です。100 に近いほど平常時のパターンと異なる異常兆候を意味します。右側の Y 軸を基準に表示されます。
- **[Score しきい値]**: Score がしきい値を超えた場合に異常と判断します。Score と同じ右側の Y 軸を基準に表示されます。

Score が Score しきい値を超えた区間が、異常状態と判断された区間です。

#### 異常検知の削除

異常検知一覧で選択した項目を削除できます。

- 削除した項目と同じ指標項目およびリソースの組み合わせで再作成すると、以前に削除された項目と連携していたウィジェットおよびアラートに自動的に再連携されます。（ただし、データ確保のプロセスが再度実行される場合があります。）

!!! danger "注意"
    異常検知項目を削除しても、該当項目を使用しているウィジェットやアラートは自動的に削除されません。
    削除された項目を使用しているウィジェットには異常検知データが表示されず、アラートも発生しなくなるため、使用しない場合は手動で整理してください。

#### 異常検知の有効化設定

異常検知一覧で選択した項目の有効化の有無を変更できます。

- **[有効化]**: 異常検知を作成すると、デフォルトで有効化に自動設定されます。無効化状態から有効化に切り替えた場合、データ確保が再度実行される場合があります。
- **[無効化]**: 該当項目の異常検知が即時停止され、該当異常検知で作成したウィジェットに異常検知データが表示されなくなり、アラートも発生しなくなります。

#### 異常検知アラートの設定

異常検知一覧で選択した項目のアラートを設定できます。

- 選択した項目が設定された状態でアラート作成画面に移動します。アラート 1 件につき 1 つのサービスの指標で作成できるため、同じサービスの異常検知項目を選択した場合にのみ実行可能です。


### 異常検知の状態

| 状態 | 説明 |
| --- | --- |
| 有効化-正常 | - 異常検知が有効化されており、正常に動作中の状態です。 <br> - ウィジェットに異常検知データが表示され、アラートが発生します。 |
| 有効化-待機 | - 異常検知が有効化されており、データ確保を進行中の状態です。 <br> - 異常検知の学習および推論に必要なデータを確保するまで、約 6 時間かかる場合があります。データ確保が完了した時点から異常検知データが表示され、アラートが発生します。 |
| 有効化-データ不足 | - 異常検知対象の収集指標データ不足により、異常検知が動作していない状態です。 <br> - サービス障害やリソース削除などにより発生する場合があります。各サービスコンソールでリソースの状態を確認してください。 <br>（リソースが削除されている場合は、該当の異常検知設定を削除してください。問題がないにもかかわらずこの状態が続く場合は、カスタマーサポートにお問い合わせください。） |
| 有効化-一時停止 | - 一時的な問題により、異常検知の動作が一時停止している状態です。 <br> - システムが自動的に復旧し、復旧完了後に分析のための追加データ確保プロセスが実行される場合があります。 <br>（この状態が長時間続く場合は、カスタマーセンターにお問い合わせください。） |
| 無効化 | - 異常検知が無効化されており、動作していない状態です。 <br> - 有効化設定で異常検知を再度動作させることができます。 <br>（ただし、有効化時に追加のデータ確保に時間がかかり、データ確保完了後から異常検知データの表示およびアラートが発生します。） |

!!! tip "ヒント"
    有効化-正常状態を除くすべての状態では、異常検知データが生成されず、それに伴いアラートも発生しません。



## 異常検知の活用

### 異常検知ウィジェット追加

独自に作成したダッシュボードにも、異常検知ウィジェットを自由に追加できます。

- ウィジェット追加画面で **[対象タイプ]** を **[異常検知]** として選択します。
- **[グラフタイプ]** は `Anomaly Detection` に固定されます。
- サービスを選択すると、該当サービスで作成された異常検知の一覧が表示されます。目的の異常検知項目が一覧にない場合は、異常検知タブで先に作成する必要があります。
- 選択した異常検知項目ごとに指標設定ブロックが 1 件ずつ追加されます。
- クエリ設定ブロックには、指標値、Score、Score しきい値の 3 つの凡例が自動的に配置されます。異常検知で作成したウィジェットは、常にこの 3 つのデータが合わせて表示されます。（ただし、状態によっては表示されない場合があります。）Score と Score しきい値の凡例名と単位、Y 軸の位置は固定値です。
- 集計をサポートする指標では集計設定を使用でき、設定した集計は指標値と Score、Score しきい値のすべてに適用されます。

!!! danger "注意"
    ウィジェットで使用中の異常検知項目が削除された場合、該当ウィジェットの照会と保存は可能ですが、削除された項目のクエリ設定値は変更できません。

#### しきい値の直接指定

異常検知はデータポイントごとにしきい値を自律的に判断するため、基準値が時点によって異なります。固定された基準を使用するには、**[しきい値を直接指定]** を選択して値を入力します。

- しきい値は 0 以上 100 以下の数値のみ入力できます。
- 直接指定した場合、データポイントに関係なく入力した値を基準に異常を判断します。
- 選択を解除すると、異常検知が判断したしきい値に従ってチャートに表示されます。

### 異常検知アラート

異常が検知された際にアラートを受信するには、異常検知アラートを作成します。異常検知アラートも既存の指標アラートと同様に、通知管理タブ > アラート作成画面から作成できます。

#### しきい値の設定

異常検知はデータポイントごとにしきい値を自律的に判断するため、基準値が時点によって異なります。固定された基準を使用するには、条件ごとに **[直接指定]** を選択して値を入力します。

- しきい値は 0 以上 100 以下の数値のみ入力できます。
- 直接指定した場合、データポイントに関係なく入力した値を基準に異常を判断し、アラートが発生します。
- 選択を解除すると、異常検知が判断したしきい値超過状態が 5 分間継続した場合にアラートが発生します。

#### 異常検知アラートの確認

- 異常検知アラートも既存の指標アラートと同様に、アラート設定タブ、通知発生履歴タブで確認でき、異常検知アラートの場合は別途バッジで区別して表示されます。
- 通知発生履歴では、**[対象タイプ]** フィルターで異常検知アラートのみ照会できます。

!!! danger "注意"
    アラートは異常検知項目が **[有効化-正常]** 状態のときのみ発生します。データ確保中、無効化、データ不足、一時停止状態ではアラート条件を評価しません。項目の状態は **[異常検知]** 画面で確認できます。
    アラートで使用中の異常検知項目が削除された場合、該当アラートの照会と保存は可能ですが、削除された項目のアラート条件は変更できません。


### 注意事項

- 項目を作成した直後は、異常検知のための学習および推論が完了するまで、Score と Score しきい値が表示されない場合があります。
- 異常検知が使用する元の指標が連続 30 分間収集されない場合、データ不足状態に変更され、Score と Score しきい値も生成されなくなります。指標収集が再開されると、状態は「有効化-待機」または「有効化-正常」に復旧されます。
