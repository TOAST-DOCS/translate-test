### 4.0.18.0(2026. 9. 22.) { #0180-2026-9-22 }

<a id="0180-2026-9-22-1"></a>
#### 기능 개선/변경

* 공유 바이너리를 사용하는 게임 그룹에서 원본 게임 기준으로 설정을 적용하도록 개선함.
* 콘솔 지표
    * URL Scheme 실행 실패 지표를 '파싱 실패'와 'gameId 유효성 실패'로 분리함.

<a id="0180-2026-9-22-2"></a>
#### 버그 수정

* 설치 취소 후 정리에 실패하면 게임이 "업데이트" 상태로 남던 문제를 수정함.
* 다운로드 취소 시 진행 중인 작업이 정상적으로 종료되지 않던 문제를 수정함.
* 런처 실행 중 URL Scheme으로 다시 실행할 때 gameId 검증이 늦게 수행되던 문제를 수정함.

    * 간헐적으로 STA 예외가 발생하던 이슈를 개선함.
* LogNCrash
    * WebView2 런타임이 없을 때 발생하는 오류를 `Unhandled_Exception`에서 `Launcher_WebView2_Not_Found`로 분류함.

### 1.0.5.0 (2024. 02. 14.) { #050-2024-02-14 }

<a id="050-2024-02-14-1"></a>
#### 신규 상품 출시

* macOS에서 게임 클라이언트를 다운로드·설치·실행할 수 있는 기능을 제공하여 안정적으로 게임을 운영하고 실행할 수 있도록 합니다.

    * Silent 모드 동작 및 게임 자동 실행 후 런처 종료 기능은 macOS 버전에서만 지원합니다.
