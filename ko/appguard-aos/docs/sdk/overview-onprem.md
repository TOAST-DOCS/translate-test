# SDK 연동 가이드

<a id="sdk-integration"></a>
## SDK 연동 { #sdk-integration }

NHN AppGuard 보호 작업을 진행할 경우 SDK 연동은 필수가 아니기 때문에 보호 작업만으로 NHN AppGuard 이용이 가능합니다. 

하지만 SDK를 연동할 경우 콜백 등록, User ID 연동, 앱 증명 등 더 향상된 NHN AppGuard 기능을 이용할 수 있습니다. 

보호 작업에 대한 부분은 [2. 보호 작업](../protection/cli-onprem.md) 장을 참고하시기 바랍니다.
앱 증명 SDK는 [6.3 앱 증명 SDK 연동](../app-attestation/sdk.md) 장을 참고하세요.
